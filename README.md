# ✈️ Flight Booking & Travel Analytics Dashboard

## 📌 Project Overview

The **Flight Booking & Travel Analytics Dashboard** is a data analytics project developed using **Microsoft Excel** to analyze flight booking data and uncover meaningful insights related to **airline performance, ticket pricing, travel routes, flight duration, stops, and booking patterns**.

The project transforms raw flight data into an interactive and easy-to-understand dashboard that supports **data-driven analysis and business decision-making**.

## 🎯 Objectives

* Analyze flight ticket pricing patterns.
* Compare **Economy and Business class** fares.
* Evaluate airline and route-wise performance.
* Analyze the impact of stops and flight duration on ticket prices.
* Study how the number of days left affects ticket prices.
* Identify important travel and booking patterns.
* Present insights through an interactive Excel dashboard.

## 📊 Key Analysis

The dashboard provides insights into:

* ✈️ Airline-wise flight distribution
* 💰 Average, minimum, and maximum ticket prices
* 🏷️ Economy vs. Business class pricing
* 🛫 Source and destination city analysis
* 🔄 Number of stops
* ⏱️ Flight duration
* 📅 Days left before departure
* 📈 Pricing and booking patterns
